Part 2 — 使用說明

每個指令的詳細說明與對話範例

任務管理

task_list 列出任務清單，預設回傳所有未封存任務，附帶 wbsNumber（如 1.2.3）並依 WBS 階層排序

參數

參數必填說明
archived否true = 只看封存；省略 = 只看未封存（附 WBS）
parentId否只回傳此父任務的直接子任務

範例

「列出所有任務」
「列出封存的任務」→ archived: true
「列出任務 abc123 的子任務」→ parentId: "abc123"
task_search 對 title 與 aliasTitle 做 case-insensitive 部分比對，結果附帶 wbsNumber。比 task_list 更快定位指定任務

參數

參數必填說明
q是搜尋關鍵字（不區分大小寫）
archived否true = 搜尋封存任務；省略 = 只搜尋未封存

範例

「找找有沒有叫 API 相關的任務」
task_search { q: "API" }
「搜尋已封存的設計任務」
task_search { q: "設計", archived: true }
task_find_by_wbs 依 WBS 編號精確查找任務，格式如 "1"、"2.3"、"1.4.2"

參數

參數必填說明
wbs是WBS 編號，如 "2.3"

範例

「取得 WBS 2.3 的任務」
task_find_by_wbs { wbs: "2.3" }
task_create 建立新任務。建立子任務時填入 parentId。mainCategory 需與系統中已有的主分類一致

參數

參數必填說明
title是任務標題
description否詳細說明
mainCategory否主分類（需已存在，可先 settings_get 查詢）
status否初始狀態（預設 TODO）
parentId否父任務 ID（建立子任務時填入）
estimatedStartDate否預計開始日期 YYYY-MM-DD
estimatedEndDate否預計完成日期 YYYY-MM-DD
completeness否初始完成度 0–100

範例

「新增一個任務叫『撰寫技術文件』，分類 Development，預計 5/10 到 5/20」
task_create {
  title: "撰寫技術文件",
  mainCategory: "Development",
  estimatedStartDate: "2026-05-10",
  estimatedEndDate: "2026-05-20"
}
「在 WBS 2 的任務下建立子任務『後端 API 設計』」
// 先查詢 WBS 2 取得 id
task_find_by_wbs { wbs: "2" }
// 再建立子任務
task_create { title: "後端 API 設計", parentId: "取得的id" }
task_update 更新任務欄位，只傳入要修改的欄位，其他保持不變

參數

參數必填說明
id是任務 ID
title否新標題
status否新狀態（見狀態值表）
completeness否完成度 0–100
completenessType否real（真實百分比）或 confidence（信心百分比）
pauseReason否暫停原因（status = PAUSED 時需填）
estimatedStartDate否YYYY-MM-DD
estimatedEndDate否YYYY-MM-DD
mainCategory / description否主分類 / 說明

範例

「把任務 abc123 狀態改為完成」
task_update { id: "abc123", status: "DONE" }
「任務 abc123 完成度更新為 75%，類型為真實百分比」
task_update { id: "abc123", completeness: 75, completenessType: "real" }
「暫停任務 abc123，原因：等待需求確認」
task_update { id: "abc123", status: "PAUSED", pauseReason: "等待需求確認" }
task_delete 刪除任務，同時刪除所有子任務。不可逆操作，建議優先使用 task_archive
⚠️ 刪除後連同所有子任務一起移除，不可逆。建議改用 task_archive。

參數

參數必填說明
id是任務 ID
task_archive  /  task_unarchive 封存/取消封存任務。封存後從主視圖隱藏，資料完整保留，可隨時取消封存

範例

「把任務 abc123 封存」→ task_archive { id: "abc123" }
「封存所有已完成任務」→ task_archive_all_done
「取消封存任務 abc123」→ task_unarchive { id: "abc123" }
task_batch_import 批次匯入多個任務，支援 children 欄位定義巢狀子任務

參數

參數必填說明
tasks是任務陣列，每筆需有 title，可含 description、mainCategory、status、estimatedStartDate、estimatedEndDate、children
parentId否掛載的父任務 ID（留空則加入頂層）

範例

「批次新增三個子任務：需求分析、系統設計、實作開發，掛在任務 abc123 下」
task_batch_import {
  tasks: [
    { title: "需求分析", estimatedEndDate: "2026-05-20" },
    { title: "系統設計", estimatedEndDate: "2026-05-27" },
    { title: "實作開發", estimatedEndDate: "2026-06-10" }
  ],
  parentId: "abc123"
}
task_reorder 調整任務在清單中的順序，或調整其在 WBS 階層中的層級

參數

參數必填說明
id是任務 ID
direction是up 上移、down 下移、promote 提升層級、demote 降低層級
task_update_snapshot 記錄任務在特定週的完成度快照，供週報使用。同一週重複更新會覆蓋（upsert）

參數

參數必填說明
id是任務 ID
weekStart是該週起始日 YYYY-MM-DD（建議填週一）
completeness是本週完成度 0–100
note否本週進度說明

範例

「任務 abc123 本週（5/11）快照：完成度 80，說明：完成後端 API 設計」
task_update_snapshot {
  id: "abc123",
  weekStart: "2026-05-11",
  completeness: 80,
  note: "完成後端 API 設計"
}

里程碑

task_milestone_upsert 新增或更新里程碑。傳入 milestoneId 時更新，否則新增

參數

參數必填說明
taskId是任務 ID
title是里程碑名稱
date是日期 YYYY-MM-DD
milestoneId否要更新的里程碑 ID（留空 = 新增）
showInGantt否顯示於甘特圖（預設 true）
color否PlantUML 顏色：Red · Gold · Blue · Green · Purple
note否備注

範例

「幫任務 abc123 新增里程碑『Alpha 上線』，日期 2026-05-30，顏色紅色」
task_milestone_upsert {
  taskId: "abc123",
  title: "Alpha 上線",
  date: "2026-05-30",
  color: "Red"
}

工作產出

task_output_add 新增工作產出（原子操作，並發安全）。有形產出填 link，無形產出填 summary。effectiveDate 用於週期型產出

參數

參數必填說明
taskId是任務 ID
name是產出名稱
outputTypeId否產出類型 ID（先 output_type_list 查詢）
completeness否完成度，如 "80%"
effectiveDate否歸屬日期 YYYY-MM-DD（週期型填，持續型留空）
link否有形產出的連結 URL
summary否無形產出的摘要說明

範例

「幫任務 abc123 新增產出『系統設計文件 v2』，連結 https://docs.google.com/...，完成度 100%」
// 1. 查詢產出類型
output_type_list → [{ id: "doc-id", name: "文件", isTangible: true }, ...]

// 2. 新增產出
task_output_add {
  taskId: "abc123",
  name: "系統設計文件 v2",
  outputTypeId: "doc-id",
  link: "https://docs.google.com/...",
  completeness: "100%"
}
「記錄本週（5/11）會議摘要到任務 abc123」
task_output_add {
  taskId: "abc123",
  name: "本週會議摘要",
  effectiveDate: "2026-05-11",
  summary: "討論了 API 設計方向，確認 3 個核心端點"
}
task_output_update 更新工作產出指定欄位，只傳入要修改的欄位

範例

「把任務 abc123 的產出 out-456 完成度更新為 90%」
task_output_update { taskId: "abc123", outputId: "out-456", completeness: "90%" }

時間紀錄

timeslot_create 新增時間紀錄，需指定明確的開始與結束時間

參數

參數必填說明
startTime是開始時間（YYYY-MM-DDTHH:MM:SS 或 epoch ms）
endTime是結束時間（YYYY-MM-DDTHH:MM:SS 或 epoch ms）
taskId否關聯任務 ID
subCategory否時間分類
note否備注

範例

「補登昨天下午 2:00–4:30，任務 abc123，子分類文件撰寫」
timeslot_create {
  taskId: "abc123",
  startTime: "2026-05-13T14:00:00",
  endTime: "2026-05-13T16:30:00",
  subCategory: "文件撰寫"
}

待辦事項

todo_create  /  todo_toggle  /  todo_delete 待辦事項的建立、切換完成狀態、刪除

範例

「新增待辦：確認 DB schema 是否需要 migration」
todo_create { description: "確認 DB schema 是否需要 migration" }
「把待辦 xyz789 標為完成」
todo_toggle { id: "xyz789" }
「清除所有已完成的待辦」
todo_clear_done

報告

report_weekly 產生週報 AsciiDoc 文字或 JSON 摘要。anchorDate 為當週任意日期，傳週五最直覺（報告範圍 Mon–Fri）

參數

參數必填說明
anchorDate否報告所在週的任意日期 YYYY-MM-DD（預設今日）
format否固定 adoc，回傳 AsciiDoc 全文
levels否顯示 WBS 階層，逗號分隔，如 "1,2,3"（預設 1–5）
excluded否排除的主分類，如 "固定會議,行政"
showTodayMark否甘特圖顯示今日標記（預設 true）
groupByCategory否甘特圖依主分類分組（預設 false）

範例

「產生本週週報」
report_weekly
「產生 2026-05-09（週五）那週的週報，排除固定會議，只顯示前三層」
report_weekly {
  anchorDate: "2026-05-09",
  excluded: "固定會議",
  levels: "1,2,3"
}
report_bi_monthly  /  report_half_year 雙月盤點（Jan-Feb/Mar-Apr...）與半年報（12-5月 / 6-11月）

範例

「產生雙月盤點報告」→ report_bi_monthly
「產生半年報，甘特圖用週刻度」→ report_half_year { ganttScale: "weekly" }
report_calendar_ics 匯出時間紀錄為 ICS 格式，可匯入 Apple Calendar / Google Calendar

範例

「匯出本月時間紀錄為 ICS」
report_calendar_ics { from: "2026-05-01", to: "2026-05-31" }

資料管理

data_summary  /  data_export  /  data_import  /  data_merge 資料統計、備份、還原、跨裝置合併
指令說明
data_summary顯示任務 / 時間紀錄 / 待辦數量等摘要
data_export匯出完整 JSON（tasks、timeslots、todos、categories、settings 等）
data_import覆蓋現有所有資料，適用從備份還原
data_merge智慧合併：依 id 比對 updatedAt，取較新版本，不影響未包含的資料
⚠️ data_import 會覆蓋所有現有資料，請確認後再執行。跨裝置同步請用 data_merge。

常見工作流程

① 當日工作記錄

1
「補登今天上午 9:00–11:30，任務 abc123，子分類程式開發」
timeslot_create { taskId, startTime: "2026-05-14T09:00:00", endTime: "2026-05-14T11:30:00", subCategory }
2
「把任務 abc123 完成度更新為 60%」
task_update { id, completeness: 60 }

② 週報生成

1
「任務 abc123 本週快照 80%，說明：完成後端設計」
task_update_snapshot { id, weekStart, completeness, note }
2
「產生本週週報」（傳週五作為 anchorDate 最精確）
report_weekly { anchorDate: "2026-05-16" }
3
複製回傳的 AsciiDoc 文字，貼入週報文件

③ 新增任務與工作產出

1
「新增任務『API 文件』，分類 Development」
task_create { title, mainCategory }
2
「列出工作產出類型」（取得 outputTypeId）
output_type_list
3
「幫剛建的任務新增產出『Swagger 文件』，連結 https://...」
task_output_add { taskId, name, outputTypeId, link }

④ 查找特定任務

A
已知任務名稱：「找任務名稱含 API 的任務」
task_search { q: "API" }
B
已知 WBS 編號：「取得 WBS 2.3 的任務」
task_find_by_wbs { wbs: "2.3" }
注意事項
• Server 必須在線（npm run dev）才能使用 MCP 工具
• 不知道 ID 時先用 task_search 或 task_list 取得
• task_delete 會連同子任務一起刪除，建議優先用 task_archive
• mainCategory 必須與系統設定中已有的主分類一致，可先 settings_get 查詢
• 週報 anchorDate 傳同週任意日期都可以，傳週五最直覺（範圍為 Mon–Fri）
