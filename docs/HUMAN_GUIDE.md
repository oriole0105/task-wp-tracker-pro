# Task Time Tracker — 使用者指南

這份指南說明如何透過 AI 助理（Claude）操作任務管理系統。  
你不需要記指令，只要用自然語言告訴 AI 你想做什麼就好。

---

## 快速開始

1. 確認系統已啟動（終端機執行 `npm run dev`）
2. 在 Claude Code 或 Claude Desktop 輸入 `/task-tracker` 啟動任務管理模式
3. 用中文告訴 AI 你想做什麼

> **提示：** 資訊不夠時 AI 會主動問你，不用擔心一次要說得很完整。

---

## 常見操作

### 任務管理

**新增任務**
```
「新增一個任務：重新設計登入頁面，分類 Frontend，預計下週一到月底」
「幫我建立任務『撰寫 API 文件』，放在 Backend 分類」
「新增子任務『設計 DB schema』，放在任務『後端重構』底下」
```

**查找任務**
```
「找任務名稱有『登入』的」
「WBS 2.3 是什麼任務？」
「列出所有進行中的任務」
「列出 Frontend 分類的所有任務」
```

**更新任務**
```
「把『撰寫 API 文件』標記為完成」
「登入頁面任務完成了 70%」
「把任務『舊版整合』暫停，原因是等待外部 API」
「把任務結束日期改到 5/31」
```

**封存任務**
```
「把『API 文件』任務封存」
「把所有已完成的任務一次封存」
```

---

### 工作時間記錄

> 每次都需要告訴 AI：**時間範圍**（幾點到幾點）、**關聯任務**（可選）、**時間分類**（可選）

**補登時間**
```
「今天上午 9 點到 11 點半，做任務『登入頁面』，時間分類：程式開發」
「昨天下午 2 點到 4 點，開會，時間分類：會議」
「補登 5/15 早上 10:00-12:00 的時間，沒有關聯任務，分類是文件撰寫」
```

**查看時間紀錄**
```
「列出今天的時間紀錄」
「查看任務『登入頁面』的所有時間記錄」
「看一下本週的工時記錄」
```

---

### 工作產出

> 工作產出是任務的「交付成果」，例如文件、程式碼、簡報

**新增產出**
```
「幫任務『撰寫 API 文件』新增產出：Swagger 規格書，類型是文件，連結 https://...」
「任務『登入頁面』的產出是一個 Figma 設計稿，目前完成 50%」
```

**更新產出進度**
```
「Swagger 規格書完成了 80%」
「登入頁面 Figma 稿完成了，設為 100%」
```

---

### 週報

**記錄本週快照（選做，影響週報的進度趨勢圖）**
```
「任務『後端重構』本週完成度 60%，說明：完成 DB schema 設計」
「更新本週所有進行中任務的快照」
```

**產生週報**
```
「產生本週週報」
「幫我生成上週的週報」
「產生 5/12 那週的週報」
```
週報預設輸出 AsciiDoc 格式，可直接貼到週報文件。

---

### 待辦事項

待辦是輕量的提醒清單，跟任務不同（不需要分類或時間記錄）。

```
「新增待辦：回覆 John 的 email」
「新增待辦：確認 staging 部署，5/18 前要做」
「列出所有待辦」
「把『回覆 John』那個待辦打勾完成」
「清除所有已完成的待辦」
```

---

### 設定（分類、成員等）

**查看目前設定**
```
「列出目前所有的主分類」
「有哪些時間分類可以用？」
「列出所有成員」
「有哪些工作產出類型？」
```

**新增設定項目**
```
「新增主分類：Infrastructure」
「新增時間分類：Code Review」
「新增成員：Alice」
「新增產出類型：測試報告，屬於有形產出」
```

## 常見問題

**Q：AI 說找不到任務，怎麼辦？**  
A：試著用任務名稱的部分關鍵字搜尋，例如「找含有『登入』的任務」。

**Q：不確定要填什麼分類？**  
A：直接說「我不確定有哪些分類」，AI 會幫你列出。

**Q：週報產出是什麼格式？**  
A：預設是 AsciiDoc，可以說「用 JSON 格式」取得結構化資料。

**Q：時間分類（子分類）有什麼用？**  
A：用來在報表中分析你的時間花在哪類工作上，例如「程式開發」「會議」「文件撰寫」。

**Q：系統沒有回應？**  
A：確認 `npm run dev` 有在跑。可以在終端機確認 `http://localhost:5174` 是否可連線。

## 小技巧

- 說「今天」「昨天」「上週五」，AI 會自動換算成正確日期
- 不確定時問 AI「目前進行中的任務有哪些？」快速掌握狀況
- 每週五花 5 分鐘：更新各任務完成度快照 → 產生週報
- 工作產出記得填連結（URL 或檔案路徑），方便之後追蹤
